# MyFirstSpring

Мой первый проект на Java Spring Boot.

## Что умеет проект:
- Запускает локальный веб-сервер на порту 8080.
- Эндпоинт `/hello` возвращает приветствие.
- Эндпоинт `/sum` возвращает результат сложения двух чисел.

## Технологии:
- Java 17+
- Spring Boot
- Maven

## Как запустить:
1. Скачайте проект.
2. Откройте в IntelliJ IDEA.
3. Запустите класс `Main`.
4. Перейдите в браузере по адресу `http://localhost:8080/hello`.
